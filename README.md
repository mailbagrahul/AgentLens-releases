# AgentLens releases

Downloads and the auto-update feed for the AgentLens macOS app.

1. Download `AgentLens-<version>.zip` from the [latest release](https://github.com/mailbagrahul/AgentLens-releases/releases/latest).
2. Unzip and drag **AgentLens.app** into `/Applications`.
3. First launch: **right-click → Open** (it is ad-hoc signed, not notarized).

After that, AgentLens updates itself: it checks daily, or use **Check for Updates…** in its menu-bar menu.
